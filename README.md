# Music Handoff — Feedback

Public issue tracker for the **Music Handoff** Chrome extension — hand off playback between
[music.youtube.com](https://music.youtube.com) and the YouTube Music app on your phone.

The extension itself is closed-source; this repository exists so users can file bug reports
and feature requests in the open.

## Report a bug

Use the [Bug report](https://github.com/EH127/music-handoff-feedback/issues/new?template=bug_report.yml) template.

## Request a feature

Use the [Feature request](https://github.com/EH127/music-handoff-feedback/issues/new?template=feature_request.yml) template.

## Support the project

If Music Handoff is useful to you, you can support development on
[Ko-fi](https://ko-fi.com/musichandoff).
